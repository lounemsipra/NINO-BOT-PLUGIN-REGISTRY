# NINO-BOT Plugin Registry

فهرس إضافات منظم لمشروع NINO-BOT.

## محتويات الفهرس

كل إضافة توصف بواسطة:
- `id`: معرّف ثابت.
- `name` و`description`: الاسم والوظيفة.
- `category` و`version`: التصنيف والإصدار.
- `compatibility` و`requirements`: التوافق والمتطلبات.
- `permissions` و`risk`: الصلاحيات والمخاطر.
- `approved`: هل تمت مراجعة الإضافة واعتمادها.
- `source_file`: مسار المصدر، وليس رابط تنزيل تلقائيًا.

## الأمان

هذا الفهرس لا ينزّل ملفات JavaScript ولا يشغّلها.
لا تعتبر الإضافة موثوقة لمجرد وجودها في فهرس عام.
قبل إتاحة تثبيت بعيد، يجب تحديد مصدر موثوق لكل ملف،
ومراجعة الكود، والتحقق من بصمة SHA-256، والتوافق مع واجهة
إضافات NINO-BOT، ثم اختبارها في بيئة منفصلة.

## النشر

هذا المجلد محلي حاليًا. لن يصبح عامًا إلا بعد رفعه إلى مستودع
GitHub عام تملكه أو تملك صلاحية النشر فيه.
